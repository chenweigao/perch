## 勘误（v2 分相计数器；原文保留为历史证据）

两处裁决及其数字。错误机制：v1 探针的 firstWriteNs/reduceNs 按**全部** parents
调用平均（16k 1706 次、64k 6536 次），其中绝大多数是空 map 平坦构建调用
（~200–300ns/次插入，非 COW 拷贝）；共享 map 调用仅 **79 次**（两档恰同，
测量协议同构），v1 稀释平均把 44.4µs/次的拷贝成本摊成 2.17µs。round-46 的
"平均入参 394 项"同属稀释口径（672922/1706）；真实共享 map 平均 **8518 项**
（16k）/ **34048 项**（64k，4.0× 线性）。教训入否定清单附注：**计数器探针
必须按调用相分类（共享 map vs 空 map），混合平均可把一个超噪声机制稀释成
亚噪声假象**——与 round-20 F3"归因 harness 同构"家族同型，新维度=调用相分布。

明示"需温路径耗时测量后再判"。本轮补该耗时测量。

入口门槛：B 授权（2026-11-27）解除 API/消费点红线，满足停止报告重启条件②。
否定清单反查：split/持久字典表示不在 20x 否定清单（round-36 采纳的是 joined
路径 COW 收养，非本热路径；round-46 探针明示 split 为开放方向）。

## 探针方法

round-46 计数探针 + 纳秒计时（.local/struct-round1/parents-time-probe.patch，
git apply --check 通过）：`firstWriteNs`=对共享 map 的首次写入（触发 COW 拷贝
+ 一次插入）；`reduceNs`=整个显式循环（含探针自身 changed 计数查找，生产不付）。
载体=base+probe 的 WorkbenchChecks release（SwiftPM，Mac mini Swift 6.4），
PerfRunner job `struct-r1-parents-time-20261127`。两档：16k（STREAMING_TURNS
默认 230）与 64k（STREAMING_TURNS=920，既有旋钮，夹具零改动）。

披露：探针显式循环 vs 生产 reduce(into:) 闭包的 codegen 差异；
DispatchTime.now() 开销 ~2×20–40ns/调用；计数器累计含预热段（与 round-46 同口径）；
单次运行（探针为机制定量，采纳裁决靠候选 A/B，非探针精度）。

## 16k 结果

```
PARENTSPROBE final calls=1706 mapEntries=672922 foldedRows=61829 changes=61829
reduceNs=27658811 firstWriteNs=3706180
chain_total median_ms=0.39  presentation_update median_ms=0.14
older_page_full_chain median_ms=1.98  commentary_chain_total median_ms=0.4523
```

- 夹具同构核验：calls/mapEntries/foldedRows/changes 与 round-46 逐值一致。
- avg firstWrite = 3,706,180/1706 = **2.17µs/call**（COW 拷贝本体）。
- avg reduce = 27,658,811/1706 = 16.21µs/call（含探针开销与 36 次正常插入）。
- **可转化份额 = 2.17µs / 390µs(chain_total) ≈ 0.56%**；即使按 reduce 全口径
  16.21/390 ≈ 4.2%（与停止报告 3.65% inclusive 吻合），其中候选仍须支付的
  插入/查找占大部分，拷贝本体才是可消除量。
- presentation_update 0.14ms 的打印格 0.01ms=7%，2.17µs 不可见。

裁决（16k）：split 假设的可转化收益远低于历史噪声带（spread 4.35–8.62%，
round-39 F1 口径），属 round-13/18/20/21"归因份额≠可转化墙钟"家族。
**16k 流式场景不立项。**

## 终裁与候选（v2 后）

**②立项**。候选=split 表示（commit e40b7054）：

- 新公开类型 `FoldParents(base+overlay)`：subscript O(1)（overlay 优先=
  flat merge 的 last-write-wins）；语义等价（flattened 比较）+ 异构
  `== [String:String]` 双向重载（既有字面字典钉死不改即过）；isEmpty/keys/
  flattened 公开。
- 热路径 `Snapshot.presented`（:426→:453）：`FoldParents(base:
  earlier.foldParents.flattened, overlay: parents(of: tail))`——History memo
  恒 flat（joined/joinedIncremental/displayed 三路），flattened 空 overlay
  O(1) 返回 base 引用；每 delta 仅重建 tail overlay（O(tail folds)≈36 项），
  消除 O(earlier) COW 拷贝。
- 分页路径保持 round-36 行为：joinedIncremental 用 flattened（flat→O(1)）
  后 COW 变异如旧；joined 逐 turn merge flattened（per-turn flat→O(1)）。
- AgentWorkbench 消费点 4 处类型标注（:430/:466/:536/:881），subscript 查找
  4 处零改动；外观零变化。
- `parents(of:into:)` 的 into: 参数移除（唯一调用点 :426 已改 split）。

钉死（checkFoldParentsSplit，113 PASS+1 SKIP Linux exit 0，portable 通过）：
- 参考端=未改 flat 算法镜像（displayedRows(activity) + ConversationProcessFold.fold
  + fresh-dict reduce），19 步差分**字节形状**比较（sorted UTF-8 key/value 对，
  round-27 N1 口径）：流式尾替换/追加 12 步、前插 4 步、纯文本尾（空 overlay
  平坦回退）、fold 翻转、summary overlay；warm/fresh Presentation 等价同步钉。
- 反盲计数器：overlay=16 / flat=3，两相均行使（首版 fixture 全工具尾→
  flat=0 触发 anti-blind trap，debug 定位后补纯文本尾步——fixture 盲区非产品缺陷）。
- 类型级：碰撞 overlay 优先、形状无关等价、异构 == 对称、keys 并集、isEmpty。
- retainingProcessEntries：opened 键离表、unopened 键仍有活 fold 行（lift 后
  剩余子项重折叠为新 fold id——首版误钉"parent 值不变"，语义更正）、overlay 空。
- 既有 checkPrependIncremental（warm-vs-fresh 9 场景组+投毒）候选上全绿不改。
- 变异电池（Linux debug，**4/4 击杀 exit 132**，树已还原+重建）：
  M1 drop-overlay / M2 flattened-ignores-overlay 均被既有 oracle 先杀
  （"presented rows must equal displayedRows and the fold"——纵深防御，
  未到新钉即死）；M3 structural-eq 被 checkPrependIncremental step 8
  （turn-boundary-growth）击杀（warm split vs fresh flat 形状不同映射同）；
  M4 reversed-priority 被类型级碰撞钉击杀（"overlay must win a key collision"；
  产品路径 key 结构不相交，M4 在产品负载下 fixture-equivalent，round-36 教训，
  类型级钉使其可观测）。
