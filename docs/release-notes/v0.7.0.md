# Perch v0.7.0

正文按阅读阶段组织，任务面板优先展示计划与产物，并记住每个会话的阅读位置。

## 正文阅读

- 区分思考、探索、执行与编辑阶段；工具输出可折叠，运行进展就近显示。
- 编辑记录支持逐步查看文件改动，历史失败与当前任务状态分别呈现。
- 运行反馈融入输入框停止按钮，减少重复状态提示。
- 修复折叠标题、文件改动统计和重复搜索结果的定位问题。

## 任务面板与文件

- 右栏优先展示计划、编辑文件与文档产物，可在面板内阅读文件。
- 按会话保留面板滚动位置、任务展开状态和文档阅读位置；关闭重开或切换会话后可继续阅读。阅读记忆限本次应用运行。
- 文件标签支持批量关闭。

## Codex 与连接

- Codex 会话支持 `/compact`，上下文不足时提供压缩提示。
- 长会话快照按消息数分页，支持继续加载更早内容。
- 桥接更新等待运行中任务结束；兼容的旧服务在等待期间继续提供会话。
- Kimi Web 更新提供立即重启入口。

## 品牌与内部改进

- 更新为木刻山形品牌图标。
- 为长会话活动叙事增加记忆化，减少重复文本分析；补充 Codex 协议检查和原生交互回归。
- 本次不承诺整机 CPU、WindowServer 或发热的量化改善，持续性能巡检仍在进行。

## 下载与升级

- 从本页下载 `Perch-0.7.0-*.zip`，解压后替换应用。
- 需要 macOS 26 或更新版本。应用为 ad-hoc 签名，未经过 Apple 公证；首次打开按系统提示操作。
- 源码用户可拉取 `v0.7.0` 后运行 `scripts/build.sh`。
