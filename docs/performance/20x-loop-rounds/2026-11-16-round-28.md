## 选题与假设

- 来源：round-25 评估轮评审 F1——"手写替代方向未关闭、不入否定清单，待 Mac 上下文内
  粗筛裁决"。队列存活候选中唯一带明确下一步门控的条目（②）；round-10 教训要求此类
  候选先在 Mac 跑目标场景粗筛再决定是否投入整轮。
- 机制：`String.utf16.count` 在产品热路径（ConversationActivity 的 progress 签名与
  outputCharacters 全窗遍历）按 UTF-8 存储逐字节换算 UTF-16 码元数。SWAR 恒等式：
  合法 UTF-8 下 units = 非续字节数 + 4 字节前导数，可 8 字节/字并行位运算。
- round-25 已归档探针（评审扩展版，双端复核）：**SWAR 只在冷缓冲首次计数获胜**
  （fresh UTF8/JSONDecoder/CoW 追加流式尾部 3.42~3.60×）；**热重数全面落后**
  （stdlib 二次计数 ~300×、ASCII 快路径 ~20×、CJK 混合 ~2.2×、与 bench 同形的
  single-turn 1000 部件 2.5×）。产品形态混合 ⇒ 净效应须实测（本轮假设：产品热路径
  以重数为主，SWAR 净效应 ≤0——待 Mac 裁决）。
- 单一假设最小修改：候选 ce901c0——`utf16CountViaUTF8` 扩展（SWAR）+ 仅
  ConversationActivity 五个计数点改路；钉死 checkSwarUTF16Count 两部分**证明范围
  不同（评审 F6 口径）**：① 穷举/结构/fuzz（1,112,064 非代理标量 × 9 案例=
  10,008,576 例：bare+8 种模 8 偏移；14 结构例；20,000 fuzz）针对钉死内**复制的
  算法副本**，证明算法恒等式；② 产品面断言经公开 `ConversationActivity
  .outputCharacters` 对 stdlib oracle（5 串 12/33/16/15/18、Σ=94），证明**产品
  接线**——评审变异重放（只对产品 helper 删补充码元、副本不动）使产品面断言先死
  （87≠94，exit -4），两部分不可互相替代。勘误：归档补丁内注释曾称穷举"经产品面"
  且 checkActivitySummaries 断言旧值 oracle——均不实（穷举走副本；既有检查无
  progressSignature/outputCharacters 旧值 oracle，signature 检查在 TurnStatus 的
  稳定性/变化性断言）；原始补丁证据不改写，以本勘误为准。Linux checks 107 PASS +
  1 SKIP（8.3s，原始日志已归档 screen-linux/linux-checks-ce901c0.log——评审 F7）。

## 裁决与处置

- **处置**：`git revert ce901c0`（d30c9fa）；`git diff b89851f HEAD -- Sources/ Tests/`
  = 0 行（产品与测试树与 main 逐字节相同）。方向②入否定清单（见 INDEX），重开条件：
  仅当未来产品路径以**冷/新解码字符串首次计数**为主且份额经归因超过目标场景噪声地板，
  并仍需 Mac 上下文内粗筛先行。
- **判定逻辑（评审 F1 对称性口径）**：采纳需要明确正向证据（Mac 未建立），保守止步
  不需要证明收益不存在；Linux 两对同向不利仅**增强**止步决定。**不声称双端合起来
  排除了所有混合负载净收益**——本轮未测该负载的新鲜度分布，Linux 效应也不能抵扣
  Mac 产品收益。outputCharacters 的**缓存变体**（round-25 F2：份额算术已更正、
  收益预期小暂不选题）判定不受本轮影响，维持原状。
- **tests 未对齐披露（评审 F4，双端适用）**：本轮粗筛两端均为 base=原始树、
  cand=base+tests/product 补丁——候选多出的 pin 可在旧产品公开 API 上编译（不属
  round-27"新类型不可对齐"例外），tests 虽不在计时中执行，**编译布局混杂风险仍
  存在**（INDEX 纪律条目）。因此两端粗筛都是**定向筛选**，不能独立确认 SWAR 的
  因果效应；保守止步不因此失效，若未来要主张强因果需 tests 对齐复测。
- **伪影披露**：首个 Mac 粗筛作业在 checks 门后一行因脚本 bug 中断（`set -u` 下引用
  未赋值的 cand_checks_exit——echo 了 `$?` 但未存变量）；checks 本身已通过
  （exit 0 / 108 PASS 在 driver 日志），续跑作业复用同批二进制（哈希首末一致证明）
  完成计时对。作业脚本两份均归档。
- **停止规则计数**：本轮为记录在案的不采纳结论——计数 +1 → **1/3**（round-27 采纳后
  归 0 起算）。
