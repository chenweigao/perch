# Round 20（2026-11-15）：presentation-token narrative 段两个机制候选——均被 Mac 上下文内粗筛否决（产品零改动，两项钉死保留）

**结论：不采纳（v1/v2 双候选撤回，产品与 base 逐字节一致）。** 场景：
presentation-token——19 轮后唯一从未归因的 bench 族，且产品自带阶段仪表
（ConversationPresentationUpdateMetrics）显示 **narrative 段
（ActivityNarrativeProjection.make）占 token 更新的 75.2%（2000 轮夹具）～
90.9%（200 轮夹具）**，每 delta ~0.11ms 恒定、与窗口规模无关（流式渲染
热路径）。两次归因、两个候选、两次 Mac 粗筛否决：

- **v1=1ac4f52**（NarrativeTextCache 文本表字节键，消 String 键 NFC 规范化
  哈希）：首跑归因（尾部 ~5KB 的 harness）显示该机制占 narrative 段
  **50.01%**；但 bench 尾部实际 ≤280B，**bench 保真复归因中份额塌缩到
  ~8%**——Mac 粗筛无分离（token200_narrative +2.8% 重叠、token2000
  -7.7% 仅 2/3 分离）。
- **v2=567529b**（L() 解析链精化：CFPreferences 单键读 + 规范标识符恒等
  捷径 + 静态 Locale 表；无缓存设计）：复归因显示 L 链 ≈ **29%+**
  （persistentDomain 全域物化、tryCast 单叶 16.45%、双遍 ICU、Locale
  逐次构造），但 Mac 粗筛**四项 token 指标中位数全部重叠且方向反而
  +2.6～+4.8% 更差**——归因份额未转化为墙钟收益的家族第三数据点
  （round-13 self-time、round-18 归属占比之后）。

两项钉死按 round-10 先例**保留**：narrative 快照黄金（4e46d66eff016205，
四方一致、逐字节相等强于规范等价）+ 本地化解析链不变量（平台条件）。
Linux 终形态 101 PASS+1 SKIP、portable 10/10（eb13b26）。停止规则计数
**1/3**。

## 归因（两次，全部归档 [round-20/attr/](round-20/attr/)；attribution-only harness 用后还原）

**首跑 round20（尾部池 1..1200 增量，~5KB 均幅；20,053 样本）**：
make() inclusive 74.74%；其中 String 键 NFC 规范化哈希行走
（`Hashable._rawHashValue → _normalizedHash`：`Hasher._combine` 18.91%、
`_fastNFCCheck`、`withFastUTF8`、`getNormData`/`getScalarBitArrayIdx`）
= **50.01% of narrative 段**；调用链 `NarrativeTextCache.value →
Dictionary.subscript → __RawDictionaryStorage.find` 样本级确证；字典探针
规范 `==` 另 ~6%。

**复跑 round20b（bench 保真：尾部 1..35 增量 ≤280B，与采纳指标同构；
20,016 样本）**：make() inclusive 52.87%；**NFC 哈希塌缩到 ~8%**（与 v1
粗筛 token2000 -7.7% 的部分改善吻合）；叶分布转为弥散固定成本，最大
单一归属为 **`L(_:locale:)` 默认参数链 ≈29%+**：tryCast 16.45%（单叶）、
strcmp 3.93%、objc_msgSend 3.69%、CFRetain/CFRelease/CFStringGetCStringPtr
~4.7%、ICU `ulocimp_getSubtags` 2.31%、`_os_feature_enabled_impl` 1.29%
——每次 L() 付 `persistentDomain(globalDomain)` **全全域字典物化+桥接**、
`Bundle.preferredLocalizations` **两遍**（默认参数 + L 主体）、
`Locale(identifier:)` 逐次构造；bench 每 delta 调 L() 2-4 次
（phase.label、localHeadline 回退、thinkingPlaceholder）。

**方法学教训（入否定清单）**：**归因 harness 的负载分布必须与采纳指标
同构**——两次归因的机制排序完全不同（50%↔8%）；round-15"孤立微基准
两个方向都不可外推"在归因侧的镜像。首跑 5KB 尾部代表真实流式（KB 级
回复），但对 bench 采纳指标不代表。

## v1 候选：NarrativeTextCache 字节键（已撤回；补丁归档 [round-20/rejected-bytekey-tables.patch](round-20/rejected-bytekey-tables.patch)）

`ByteText`（UTF-8 字节相等 + 连续缓冲单遍 SipHash，异质存储拷贝保证等
字节等哈希）+ `CleanKey` 结构体（消 `"\(limit)\u{1}\(text)"` 插值键全文
拷贝）。等价论证：字节相同 ⇒ 命中不变；NFC/NFD 规范等价字节变体由共享
条目变各自条目+重算，表后派生（clean/phase/narrativeText）规范协调、
下游仅经规范 `==`（本身规范化不变，同 String 哈希与渲染）观察 ⇒ 不可
观测。

**钉死捕获期的重要发现**：语料含 NFC+NFD 变体对时，未改产品（共享条目、
返回先到者字节形态）与候选（逐变体重算）的黄金摘要**合法地不同**
（726a314a… vs db78d984…，而 staged/keyword 计数完全一致）——按 round-17
先例把变体对移出语料（合法字节形态分歧由结构例钉：NFC/NFD 快照规范
`==` 相等），收敛后黄金 **4e46d66eff016205 在未改产品捕获、四方一致**
（Mac/Linux × 基线/候选；逐字节相等，强于规范等价承诺）。结构例：重复
命中等值、标记剥离、limit 分离（tool 路径 "…" 断言，locale 无关）、空白
无阶段、确定性双跑、密度守卫（1382/1500 staged、883 keyword-phased）。

**粗筛（3 轮交替，上下文内）**：Mac token200_narrative 中位
0.1094→0.1125（+2.8%，重叠；基线 it1 0.1986 离群）、token200_total
+2.9%、token2000_narrative 0.1133→0.1046（**-7.7%，仅 2/3 分离**）、
token2000_total -5.3% 重叠、cold@2000 重叠；Mac 双侧 checks 101 PASS、
黄金 Mac 两方复证。Linux 全指标重叠（token2000_narrative -2.8% 3/3 但
幅度近打印格）。**判定：Mac 未达分离标准 → 否决**（机制仅在 KB 级尾部
成立；bench 采纳指标不敏感）。钉死保留（见终形态节）。

## v2 候选：L() 解析链精化（已撤回；补丁归档 [round-20/rejected-lean-l10n-chain.patch](round-20/rejected-lean-l10n-chain.patch)）

**设计约束**：LocalizationChecks 直接写 UserDefaults 并逐调用断言立即
生效——**事件失效缓存方案被行为钉死禁止**；v2 保持逐调用活读，只删
冗余：① `.system` 分支 `CFPreferencesCopyValue` 单键读全局域
AppleLanguages（与 `persistentDomain(globalDomain)?["AppleLanguages"]`
同源同转换语义，Darwin-only，等价性钉死）；② L() 主体对规范标识符
（"zh-Hans"/"en"）走恒等捷径（前提 = `preferredLocalizations(from:)` 精确
匹配自身，钉死）；③ `resolvedLocale` 双条目静态纯值表 + 原回退。Linux
`#else` 原路径不动（构成无变化护栏，round-16 先例）。

**粗筛（3 轮交替）**：Mac token200_narrative 中位 0.1042→0.1087
（**+4.3%**）、token200_total +4.8%、token2000_narrative +4.5%、
token2000_total +2.6%——**四项全部重叠且中位方向更差**（逐轮符号不一
致：it3 -8.3% vs it2 +5.4%，噪声带内）；cold@2000 重叠；双侧 checks
101 PASS、黄金完好。Linux 如预期零信号（全指标重叠，#else 未动 =
语义可证未变）。**判定：否决，且按 round-13 先例把一致向差的中位数
披露为弱回归信号（不保留改动）。推断（HYPOTHESIS）**：CFPreferences
进程内域缓存已摊薄 persistentDomain 物化成本，单键读不更贵也不更便宜；
tryCast/objc 份额或系 CFPreferences/NSBundle 内部机制而非字典物化本身
——29% 归属份额零墙钟转化。

**验证环境处置（如实披露）**：粗筛 job 内 `check-localization-runtime.sh`
双侧 exit **137**（SIGKILL）——`WORKSPACE-DESIGN.md:166` 早已记录该脚本
在测量 mini 上无法执行（裸 swiftc 二进制被杀；且经核查该脚本**不在任何
CI 组内**，仅文档引用）。按 INDEX 规则改 SwiftPM scratch 包：mini 上
**编译验证通过**；运行时 `.app` 组装（硬链接二进制）仍 **137**——
round-18"原地运行"规则的**新数据点：重定位经硬链接同样被杀**；浅 bundle
原地运行可执行但 Bundle 资源不加载（exit 133，环境伪影非产品缺陷）。
⇒ **新钉死运行时载体移入 WorkbenchCoreTests**（SwiftPM 原地可跑；CI
core-regression 在 macOS runner 执法）。

**平台分歧发现（探针归档 [round-20/checks/](round-20/checks/)）**：
corelibs `Bundle.preferredLocalizations` **完全忽略 preferences**、恒返回
首候选（6 组输入实测；Apple 侧为 ICU 匹配语义）。产品 Linux 侧永不走该
链（L() `#else` 返回 `value.resolved`），分歧为潜在无害——钉死按平台
条件（round-17 先例）：Darwin 断言 ICU 语义（含 v2 恒等捷径前提与
CFPreferences 等价前提——为未来重试留证据）+ Linux 断言实测 legacy 行为
防漂移。

## 机制与方法学记录

- **归因 harness 负载必须与采纳指标同构**（本轮核心教训，入否定清单）：
  尾部文本 5KB→280B 使机制排序反转（NFC 哈希 50%→8%）；两次归因都
  真实，但只有保真版对 bench 采纳有效力。
- **归因份额≠可转化墙钟**第三数据点：v2 的 L 链 29%+ 份额 → 0 收益
  （+2.6～+4.8% 弱反向）；与 round-13（self-time 8.64%→-1.65% 带内）、
  round-18（归属 1.88%→-0.07%）同族。粗筛制度化（round-15）第三次
  在正式六对之前拦下无效候选，节约两轮全量 A/B。
- **narrative 段 bench 尺度构成**（复归因）：无单一机制 >4%——弥散固定
  成本（小字符串比较/字典/ARC/CF/锁）+ L() 链；队列中该场景标记为
  已探明低余量。
- mini harness 限制新增数据点：重定位 SwiftPM 二进制**含硬链接**均
  SIGKILL（round-18 原地规则强化）；浅 bundle 原地可跑但资源不加载。
