## 改动（e2ff3c0；单文件 `ActivityNarrative.swift` + 新钉死文件）

`NarrativePhaseScan`：单遍 UTF-8 字节扫描——首字节大小写折叠分桶
（256 桶静态表）、ASCII 关键词大小写不敏感字节比较、CJK 关键词字节
精确比较；命中后**双侧边界证明**（round-17 技术：前驱字节 ASCII 或串
首、后随字节 ASCII 或串尾——一切 Prepend/Extend/SpacingMark/ZWJ 标量
均非 ASCII，故 ASCII 邻接即 grapheme 精确）为**确认匹配**；边界不可
判定 ⇒ **回落原规范谓词**（`lowercased().contains(kw)`，惰性只求值一次，
逐平台逐位复现旧行为——含 round-17 探针记录的 GB9b 平台分歧）。优先级
解析严格按原 if 链：四级 confirmed→fallback 逐级。

- **等价论证（产品注释全文在案）**：① 无假阳性——确认匹配的关键词
  字符为独立 grapheme 且字节连续 ⇒ 旧谓词必命中；② 无假阴性——旧命中
  要求 lowercased 文本中关键词字符连续；ASCII 关键词只能经"非 ASCII
  标量小写为纯 ASCII"获得新字节，穷举扫描证明该桥**仅 U+212A→'k'**且
  32 关键词无一含 'k'；CJK 表意文字大小写/规范化不变、不可能由组合
  序列产生；③ 不可判定命中走原谓词 ⇒ 平台分歧行为逐位保留。
- `Sources/AgentWorkbench` 零差异；Linux 与 Darwin 同一新代码（回落
  谓词本身逐平台语义不变）。

## 行为等价钉死（checkNarrativePhaseSinglePass，新文件）

1. **穷举标量桥接扫描**：全部 1,112,064 个有效标量逐一断言
   `String(s).lowercased()` 为纯 ASCII ⟺ s 为 ASCII 或 s=U+212A；并断言
   U+212A→"k"、32 关键词表无 'k'/'K'（无假阴性论证的两条腿都被运行时
   钉死，任何平台/工具链 Unicode 表漂移都会 trap）。
2. **差分模糊（round-16 v2 运行时差分模式，版本鲁棒）**：参考实现=被
   替换谓词链的逐字拷贝；2,000 条 seeded 文本（碎片含全部 32 关键词、
   大小写变体、片段，四类 GB9b Prepend 标量邻接（U+0600/U+06DD/U+08E2）、
   Extend/ZWJ 邻接、词内组合符（te◌́st）、U+0130/U+212A 桥、emoji 邻接、
   CJK 混排）经 projection 公共路径（clean-stable 语料保证 phase 输入=
   注入文本）与参考实现**逐一相等**；密度守卫（对抗文本 >200——实测
   993；五类别各 >20——实测 validating 867/editing 341/integrating 404/
   exploring 195/mixed 193）。
3. **结构例 36 条**：32 关键词逐一到类别映射 + 跨类优先级三例 +
   无关键词对照。
4. **既有 narrative 黄金 4e46d66eff016205 原样通过**（round-20 钉死，
   1,500 脏语料文本端到端含 Prepend/组合符/ZWJ/emoji/NBSP/标记片段——
   关键词富集语料 "验证测试"/"构建"/"edit fix"/"git commit"/"读取
   search"/"分析查看" 直接覆盖 phase 路径）；Linux 捕获期与本轮双侧、
   Mac 粗筛与正式双侧全部复证。
