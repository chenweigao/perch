## 机制与方法学记录

- **归因→墙钟转化差距第三数据点（更正后口径）**：round-13 self-time
  8.64%→-1.65%、round-18 归属 1.88%→-0.07%、本轮表机制并集 -17.77pp
  （of all）→ longtail wall -3.5%。份额的可迁移性取决于机制成本对运行
  环境的敏感度（内存层级/驱逐动力学、分支短路分布——均 HYPOTHESIS 级
  解释）；round-17/19 的扫描类机制近似 1:1 迁移是该规律的对照面而非
  普适保证。
- **stdlib API 热路径陷阱（实证范围精确化，入否定清单附注）**：
  ① `String.UTF8View.elementsEqual`（及同族 Sequence 算法）经
  IndexingIterator 的逐字节 `Collection.subscript` witness——本轮实证
  （1,892 样本/11.08%），KB 级文本上与 NFC 哈希同量级；②
  `withContiguousStorageIfAvailable` 对非原生存储（实证例：桥接
  NSString）返回 nil，对 substring-backed String 的 nil 频率**未归档
  实验、不作断言**（初版概括已撤回）。字节级操作正解：
  `String.withUTF8`（mutating——需局部 var COW 副本；任意存储给连续
  缓冲），本轮 v2 实证将 ByteText 机制从 24.30% 降至 9.51%。
- **粗筛均值回归**：n=3 的 -9.5% 在 n=6 回归至 -2.52%；临界候选必须
  扩展粗筛再裁决。
- **护栏回归信号必须全量披露**：初版"护栏无变化"漏报两处分离信号
  （复核发现 3）——粗筛报告义务覆盖全部采集指标而非仅主指标。
- **画像-基准同构性第四维**：分支短路负载分布（phase 谓词命中位置）
  与前三维（输入规模/命中分布/容器动力学）并列。
- mini harness 无新伪影：本轮全部二进制原地运行、等价输出非空校验、
  Mac 双侧 checks 全绿。
