# 目录刷新、搜索复用与原生历史增量加载

## 实现

1. 原生会话目录：运行中每 2 秒、空闲时每 5 秒更新。正文和发送回执仍走 400ms 的正常周期；发送操作立即同步目录，当前会话完成/审批变化会让下一周期同步目录。其他会话的外部变化最多受目录周期约束。未增加模型调用。
2. 正文增量：首次只取最近 50 个用户轮次；后续用历史 epoch、版本和绝对消息位置传输新增/改动消息。取消临时流式消息通过总长度收缩表示。桥接服务复制和编码本次变化，不再每次复制全部历史；消息位置索引和最后修改版本按历史消息数增长，不按 token 事件数增长。
3. 会话搜索：缓存可搜索字段和结果；同一目录/语言/查询复用结果与在线行索引。目录、语言和查询变化会失效。保留多关键词、大小写、变音符号、离线选择和归档过滤规则。
4. 历史分页：向上滚动接近顶部时补载，也可点击“加载更早消息”。前插后保持阅读锚点；会话切回恢复之前已加载的窗口。顶部固定入口“加载全部轮次”和查找栏“搜索完整历史”按页补齐全部内容，随后支持全局搜索和全部轮次跳转。未补齐时导航覆盖已加载轮次，搜索栏明确范围。

## 一致性

- history epoch 在桥接进程重启或历史整体替换时变化，旧位置不能用于新历史。
- 页数据不推进当前正文版本，下一次增量会对齐与分页交错的历史编辑。
- 若在途增量只覆盖补载前的旧窗口，客户端丢弃它且不推进版本，下一正常周期请求扩展后的窗口，避免漏消息。
- 切换/断开取消分页；迟到结果不得污染新会话。并发分页请求被合并为一次加载。
- 系统通知和工具加载上下文不计作用户轮次，分页边界保留完整回复上下文。
- 新服务仍支持旧客户端的完整响应；新客户端可读旧服务完整响应，但分页/增量收益需更新远端桥接组件。

## 合成规模实验

通过 `scripts/benchmark-native-loading.py` 直接调用本仓库桥接实现，包含复制和 JSON 编码；不启动 Agent、不读取真实会话。每轮固定中英文本长度，7 次采样取中位数。

| 历史轮次 | 完整响应 bytes | 首次 50 轮 bytes | 一条变化的增量 bytes |
| ---: | ---: | ---: | ---: |
| 200 | 185190 | 46458 | 611 |
| 2000 | 1855790 | 46561 | 616 |
| 10000 | 9287790 | 46564 | 620 |

一万轮的首次响应约为完整响应的 0.50%。该合成场景中复制及编码的中位数约为：完整响应 104.09ms、首次分页 0.49ms、单条增量 0.02ms。数字不代表真实 SSH 延迟、硬件输入延迟或 FPS；实际页大小还随单轮内容长度变化。

搜索另测 500/2000/10000 个合成会话，比较原算法一次筛选与缓存字段后的新查询，并断言结果一致。具体采样保留在 measurements.json；同查询重复求值复用结果。未将先前报告的布局耗时与本轮算法计时混算。

## 验证

- 集成基线：`7a702ff`；实现提交：`2af8dd9`。
- Python 桥接 92 项测试通过，覆盖 HTTP 参数、完整分页、同 ID 修改、临时消息移除、历史替换及可变工具参数别名。
- Swift 与实际 Python 桥接产生的包逐项对照，分页加增量合并结果应等于完整历史切片。
- 最终整合版本的 Release 构建、严格签名、WorkbenchChecks 和 ConnectionChecks 通过；包括旧窗口增量与新补载页交错的连接级回归。
- 原生窗口分页、完整搜索/首尾轮次跳转、会话切换、输入和目录筛选验收通过；自动窗口回放结果及二进制指纹见 measurements.json。
- CUA 实际窗口上滚将 50 轮补到 100 轮；点击“加载全部轮次”后为 200 轮，仍停在原来的第 150 轮附近。正文、表格、代码和链接颜色正常。此观察不等同于物理触控板帧率测试。
- 初次分页验收在视图导航异步发布前读取轮次数而失败；验收改为等待完整导航状态，保留锚点和 200 轮数量断言，最终通过。原始结果保留在 `.local/incremental-loading/paging/`。

## 范围

本次针对原生 Agent 桥接通道。Kimi 自身已有独立的分页/事件协议，保留原行为；本地目录搜索改动适用于统一会话目录。第一次打开取最近窗口，主动查看更早历史会逐步增加本地已加载内容，未做看过页面的强制淘汰。首次切回会恢复已加载范围，以保留阅读位置。

未安装替换用户 App、未部署远端桥接服务、未推送。原始日志及隔离验收数据保存在 `.local/incremental-loading/`；帧率和真实模型/SSH 场景不属于本轮已验证结果。
