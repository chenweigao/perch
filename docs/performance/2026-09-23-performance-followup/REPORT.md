# 搜索、正文首次阅读与联合负载优化（Mac mini，2026-09-23）

## 改动

1. `SessionKind.label` 使用 switch，只在 terminal 分支执行动态本地化。保留所有 Agent 名称（包括 Claude Code）、搜索匹配规则和语言切换。
2. 原生段落视图销毁时清空内容、选区、代理与正文标记；仅在 SwiftUI 已将其从视图树和窗口移除后复用。池上限 64，不增加正文宿主的保留范围。验收构建断言复用对象不残留上一行状态。
3. 正文富文本颜色保留为动态 NSColor，在目标外观下解析颜色与透明度。原始实现也能复现“浅色窗口中部分文字变白”，所以单独修复这个已有缺陷。
4. 新增仅验收构建可用的正式工作台联合场景：200 轮完整历史，2.5Hz 全量 JSON 更新、草稿输入、每两秒滚动和反复切换。逐次检查草稿、阅读位置、文字对比度和视图数量。
5. 运行原有 Composer/Localization 契约检查；本机新编译的小程序首次启动出现 SIGKILL，随后显式执行成功。尝试增加签名步骤未能稳定解决首次启动，故未改动原检查脚本。

阅读来自 Navigation Preview；正式工作台指标来自 NativeAcceptance，二者不混算。计时包含程序化状态变化、布局、display/CA flush，**不是 FPS、硬件输入延迟或触控板惯性流畅度**。三对样本用于本机探索；会话切换基线各轮 p95 为 84.58/111.25/101.92ms，存在波动。最终 A/B 期间另有固定 2.5Hz 联合场景持续运行，不能与旧报告跨场景直接计算收益。

CPU 归因使用各版一次短 Time Profiler，按进程和 signpost 切片。DirectoryQuery 中 SessionKind.label 的 inclusive 样本从 429ms 变为未采到，resolvedLocale 从 229ms 变为未采到；HistoryScroll 中文字视图创建路径从 75ms 变为 13ms。单次采样作为机制证据，不能直接推算稳定加速比；调用栈权重相互包含。

## 长时资源

最终 30 分钟联合运行通过（1800.20 秒），共 4431 次更新、294 次会话切换；草稿、阅读锚点、回切位置、对比度及视图数量断言全部通过。测试以 400ms 间隔推进，保留完整历史，尾部内容长度受限，避免把合成负载本身的无限增长误认为 UI 泄漏。每 30 秒记录 RSS、进程 CPU、宿主和复用池数量；CPU 包含 fixture JSON 序列化与驱动开销。早期阶段与构建、短采样及 A/B 并行，延迟数据不作为隔离性能成绩。

采样 RSS 为 104.13–205.56 MiB，结束并静置后为 186.69 MiB（开始前 164.56 MiB）。中途回落后又缓慢回升，不能由这一次运行推断完全无泄漏。六个 5 分钟窗口的 RSS 中位数依次为 186.59、151.12、127.87、142.99、163.55、177.91 MiB。采样最大 mounted/retained/retired 为 5/6/4，复用池最大 54（上限 64）；每次更新另有数量断言，未见宿主堆积。

进程 CPU 共 167.96 秒，约为单核时间的 9.3%，包含合成数据生成与验收驱动。程序化草稿到布局 p95 为 11.94ms，更新到布局 p95 为 31.40ms；仅作该联动场景记录，不等同于真实键盘输入或网络流式延迟。

## 失败保留与测量边界

- 原始正文实现、原始复用候选和新增容器试验均复现浅色文字对比度失败。容器试验撤销，最终仅保留最小视图复用及动态颜色修复。
- 一次修色后的短联合运行发生 readiness timeout，未改宽断言；增加上下文后相同断言短测通过。该失败保留为 `ink-joint`，不能当作已定位的根因修复。
- 初次长测运行约六分钟后，为排查实际窗口颜色问题主动停止；它不算长测通过。最终长测另起目录。
- Animation Hitches 在锁屏和解锁保持唤醒后各做一次 120ms 已知停顿校准，均没有可关联到应用的帧生命周期数据，状态为 unverified。不能报告“0 卡顿通过”；尚无可靠帧验收结论。
- 原始日志、trace、每步结果、候选二进制及失败证据保留在 `.local/performance-followup/`。汇总见 measurements.json。
