## 归因（新：纯冷查询专剖，base=15f612f）

临时 loop harness（`findbar-profile` 模式，用后还原、porcelain 0；job 与
runner 日志归档 [round-16/attr/](round-16/attr/)）：fixture 建一次，循环
"新建 ConversationSearch + 全窗 hits()"。冷查询中位数 **1,597ms**
（4 次迭代，harness 上下文计时、非 A/B 口径）；21,067 样本按**调用点**
（每个热点叶帧向上走到最近产品帧）分解：

| 归属 | 占全样本 |
| --- | --- |
| **linkMatches（NSDataDetector 裸 URL 检测）** | **~26%**——`_nativeGetIndex` 的 98%（全样本 8.51%）、`langid_consume_string` 100%、DD 词法/扫描/缓存帧 100%、`__CF_IS_OBJC` 99%、`objc_msgSend` 96%、`_nativeCopy` 88% |
| `ReplyDocument.parse`（cmark + normalizeDelimiters） | ~14% |
| CF 查询匹配循环（`range(of:)` 语义红线） | ~5.7% |

机制：检测器经 `character(at:)` 逐 UTF-16 单元读取**惰性桥接**的 Swift
字符串（`@objc __StringStorage.character(at:)` → `String.UTF16View.
_nativeGetIndex`）。round-15 报告曾把该区域整体归入"CF locale 匹配
（语义红线）"——本轮调用点级归因证明其中最大块实为**产品侧可控**的
NSDataDetector 输入桥接，红线边界据此重画（查询匹配语义本身未触碰）。

## 粗筛 #1（否决）：搜索 haystack 物化

把 ConversationSearch 的合并搜索文本也物化为连续 UTF-16：等价 PASS
（1,155 组比较），但计时**按查询脚本分裂**——CJK 查询（产品代表形态）
全部变体 **+13.5～+21.8% 更慢**，ASCII 查询 -9～-25% 更快。机制（推断）：
CF 对惰性桥接的 Swift 原生字符串保有 UTF-8 直读快路径
（`_CFStringGetCStringPtrInternal` 叶帧），强制 UTF-16 反而丢之。
**不开轮，入否定清单**；全记录
[round-16/screening/SCREENING-RESULT-haystack-materialization.md](round-16/screening/SCREENING-RESULT-haystack-materialization.md)。

## 改动（7b4318f + 黄金嵌入 9e7bc19；`ReplyDocument.swift` 单产品文件）

`linkMatches` Darwin 分支把 `linkDetector.matches(in:)` 的输入换成
`contiguousUTF16(text)`——`CFStringCreateWithCharacters` 物化的连续 UTF-16
字符串（同一字符序列 → 同一检测器 → 同一匹配/拆分/渲染/命中）。空串
直通；canImport(CoreFoundation/Darwin) 守卫，**Linux regex 回退分支零
改动**。`Sources/AgentWorkbench` 零差异。

## 行为等价钉死

`checkLinkScanContiguousUTF16()`：parse 输出规范化序列化（公开字段：run
文本/粗斜删码/链接 URL/math latex/列表标记/表格对齐/alert 种类），
**3,000 文本 seeded 模糊语料**（URL 形态 × `$` × CJK × NFD × emoji ×
标点碎片）摘要 FNV-1a 黄金值 + 确定性双跑断言 + 结构固定例（链接守恒、
math 与 URL 共存、**跨 URL 的 `$` 对因先拆分而保持字面**）。黄金值在
**未改产品**（15f612f+本测试）上按平台捕获：Mac `97e345c9136b50c8`、
Linux `5dd61f867727616a`（两后端在边缘形态上合法分歧——Darwin 检测器
把尾随 CJK 卷进 URL、把粘连的 "xhttps" 当未知 scheme；Linux regex 均不
——故按平台各钉各的摘要）；候选两侧在同平台复现**同一摘要** = 等价证明。
matched baseline 编译且通过（两侧同绿，无预期失败）。

**平台分歧记录**：固定例初版编码了 "$ 粘连 URL" 形态，仅在 Mac trap
（NSDataDetector 读 "xhttps" 为未知 scheme → 不拆分 → math 提取；exit
133 @ 49 PASS，双侧一致、日志归档
[round-16/checks/macos-pin-divergence-trap.log](round-16/checks/macos-pin-divergence-trap.log)）；
探针取证（[round-16/screening/detector-probe/](round-16/screening/detector-probe/)）后
改用 CJK 分隔形态，**发生在任何测量之前**，产品行为自始未受影响。
