## 行为等价钉死（checkConversationEntryCache，新）

- **Part 1 机制（v4 形态）**：键**单射性三层钉死**——NFC/NFD query 异键（长度前缀
  下规范比较亦不碰，但字节级等值仍是唯一正确语义）、NUL 内嵌碰撞对（"a\0b"+"c" vs
  "a"+"b\0c"）、**等长规范重排对 + 字典级检索拒绝**（orderA 键存、orderB 键取必须
  nil——只有这一层能击杀表内 Key 规范化变异体，v3 教训）；options/running 位区分；
  **验证谓词是唯一复用门**——同 ID 编辑消息拒绝复用（值层失败）、**规范相等 NFD
  重建拒绝复用**（值层通过、渲染字节层拒绝=round-12 sameRenderedMessages 推理的
  跨实例化）；**留存全计准入成本**（admissionCost==estimatedCost+key.count+
  query.utf8.count 逐值断言）；budget-0 永不入表（无缓存 oracle 制度）；具体 LRU
  （touch 保留+受害者身份+新插保留）；非空表超大**载荷**与超大**键**双拒绝（哨兵零
  扰动）；**世代守卫 store**（捕获→通知→拒绝）；locale 世代（真实通知 POST→整表
  丢弃）；removeAll（诊断语义）；8×100 并发风暴+单份记账（==Σ25 键各自 admissionCost，
  k10+ 键长差 1 字节按各自成本求和）。
- **Part 2 端到端**（round-27 语料：NFC/NFD 变体、独立消息重复 source、display math、
  URL/代码）：四制度（budget-0 双层 oracle / shared 冷 / fresh / shared 温）× 6 查询
  规范级+**逐 hit UTF-8 字节级**全等（round-27 v5 byteShape 比较器）；**跨实例
  staleness**：温缓存后以同 ID 编辑窗口经新实例搜索，与 budget-0 oracle 规范+字节
  全等（skip-verification 变异体死于此）且编辑后新命中（BETA）在场；running 标志
  隔离（true/false 不串节点）。
