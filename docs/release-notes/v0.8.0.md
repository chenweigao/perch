# Perch v0.8.0

Kimi Code 改为原生 ACP 桥接接入，界面布局与 Qoder 对齐，正文流式渲染与连接链路完成一轮性能整理。

## Kimi Code 与桥接

- Kimi Code 从托管 Web 服务迁移到原生 ACP 桥接（Provider：kimi），与 Codex、Claude 等本地代理同构。
- 桥接协议升级到 v14，修复 ACP 会话记录被拆分后的拼接；提示词在桥接配置同步完成后才发送。
- 恢复 Codex 会话的 `/compact`。

## 布局与界面

- 侧栏、窗口外壳与会话正文与 Qoder 布局对齐；标题行并入统一工具栏。
- 输入区对齐 PI：模型与思考强度胶囊、上下文百分比环；模型菜单采用最近使用与按来源双栏。
- 检查器与主容器整合，输入区、过程行与侧栏视觉权重收尾打磨。
- 侧栏会话行改用原生悬停预览与操作菜单，项目子菜单补齐本地化。

## 正文阅读

- 排版节奏与 DSH 桌面对齐：代码卡横幅、表格几何；表格支持复制、CSV 导出与放大预览。
- 思考流并入对应操作行并就地流式预览；运行中的实时状态行带时钟，静默时明确提示。
- 引用的上下文作为输入框内联引用，可经原生纯文本复制导出。
- 正文滚动锚定到稳定行，过程折叠后保持阅读位置。

## 性能

- 正文流式渲染复用稳定结果，流式回复开销移出主线程。
- 会话隧道复用主机的共享 SSH 连接，桥接由快速轮询改为长轮询。
- 本次不承诺整机 CPU、WindowServer 或发热的量化改善，持续性能巡检仍在进行。

## 下载与升级

- 从本页下载 `Perch-0.8.0-*.zip`，解压后替换应用。
- 需要 macOS 26 或更新版本。应用为 ad-hoc 签名，未经过 Apple 公证；首次打开按系统提示操作。
- 源码用户可拉取 `v0.8.0` 后运行 `scripts/build.sh`。
