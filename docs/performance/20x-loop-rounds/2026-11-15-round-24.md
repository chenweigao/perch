## 缺口与产品面

`String.collapsedWhitespace`（WorkbenchCore，被 narrative 派生
（ActivityNarrative.swift:197）、ConversationProjection 摘要
（cronFire prompt / text prefix(320)）、ConversationThinkingSummary
使用）文档契约为"等于 `split(whereSeparator: \.isWhitespace).joined(separator: " ")`"。
字节快路径对 **7 个标量**违反该契约（round-11 穷举走查按现状特征化
在案，双端同为 7 个）：泰文 Sara Am U+0E33、老文 Sara Am U+0EB3、
emoji 肤色修饰符 U+1F3FB–U+1F3FF。机理：工具链自身的 grapheme 分割把
它们与**前置空格**融合为一个 Character，且该融合簇的 `isWhitespace`
为 true ⇒ strict 形态把整簇（含标量本身）作为空白丢弃；快路径此前把
标量当普通内容保留。具体分歧：`" \u{0E33} "` strict=`""`、修复前
快路径=`"\u{0E33}"`。产品对应面：泰/老文与带肤色修饰符 emoji 的
会话摘要/叙事文本在空白邻接位置的截断/折叠结果。

## 改动（v1=172fd87 产品逻辑；v2=c3d38a2 评审 F1/F6 注释与输出行逐字更正——产品逻辑零改动；产品单文件 + 钉死单文件）

**产品**（ConversationProjection.swift）：`beginsBindingMark` 增加
**钉死融合集** `isPinnedFusingScalar`（0x0E33、0x0EB3、0x1F3FB…0x1F3FF），
与既有 `isPrependScalar`/`isNeverBindingScalar` 同一契约：过包含安全
（多余的 strict 回落、绝不产生错误答案），集合可以领先 Unicode 数据
但绝不允许落后；命中即整串走 strict——契约按定义恢复。位置在
never-binding 预筛之后、属性查询之前（七个标量均不在 never-binding
区间；整数比较先于属性表查询）。

**钉死**（CollapsedWhitespaceTests.swift）：
1. **穷举 whitespace-adjacent 走查升级**：detected 谓词镜像产品钉死
   融合集；`characterizedGap`（旧：按现状计数 7）改为 **`fusionGap == 0`
   硬断言**并列出违例标量——Unicode 数据漂移出现新融合标量时检查
   响亮失败（与 Prepend 集滞后的既有处置同一契约）。
2. **16 个结构例**：七标量的前导/词中/多空格 run/词尾/单独形态 +
   快路径对照（字母后、emoji 基后——修饰符融合在基上时**不**触发
   回落，输出字节保留）。
3. **专用 fast-path 模糊（新）**：既有混合语料含非 ASCII 空白恒走
   strict、从不行使字节路径——新增 500 条 seeded 文本，碎片含七标量、
   组合符、ZWJ、emoji 基、CJK、多空格、CRLF，逐条对照 strict oracle。
   计数器语义（评审 F1 更正）：**259 条不含潜在 strict 触发标量、
   241 条含至少一个潜在触发标量——语料分类而非执行分支计数**（分类

   304 条实际走字节路径、196 条实际 strict，45 条误标）。偶数半区
   仅由快路径碎片构成（不含任何触发标量），**保证字节路径覆盖的
   论证仍成立**；双计数器守卫保留。
4. 既有钉死全绿不动：3,000 片语料、Prepend 穷举（27 融合标量）、
