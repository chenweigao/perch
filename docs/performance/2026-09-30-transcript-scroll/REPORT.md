# 正文上下滚动：定位与两项被撤回的候选

用户确认问题在整个会话正文，而不是展开后的独立长输出阅读区。本轮以最新主线
`3e7aa29` 为基线，复现 200 轮混合正文的完整下读、上读及短距离反复换向。
**两项候选都未达到可采用的收益，生产渲染器保持主线实现。**

## 构建来源与剩余尖峰

当前运行的真实客户端标记为 build 306 / `v0.1.0-168-gdc778f2`，不包含 PR #78 的
候选代码；本轮没有据此否认卡顿，也没有把旧客户端体感计入新主线的性能测量。
切换正在运行的客户端需要中断窗口操作，已单独请求用户允许。

主线首次基线运行：完整向下 335 步，中位数 9.37ms、p95 18.83ms、最大 24.90ms，
39 步超过 16.7ms；向上 334 步，中位数 6.18ms、p95 13.94ms。覆盖所有 200 轮及末尾。
这些是程序修改滚动位置至布局/display/CA flush 的耗时，不是硬件滚轮输入或显示帧率。
新内容进入视口时仍有工作尖峰，不能把“已合并架构优化”解释为正文体验已经达标。

同轮下读计数中，477 次首次行测量累计约 722ms，文本测量约 219ms，Markdown 解析
约 114ms，几何索引重建约 5ms。计时阶段相互嵌套，不可相加。没有优先重写行索引
或引入 TCA 的依据。

另行串行采集 Time Profiler。`cpu-summary.json` 中约 9,508ms 主线程样本里，
`NSHostingView.layout` inclusive 约 4,845ms，`UserMessageLayout.sizeThatFits` 约
1,106ms，行释放约 808ms。**采样包含完整 reading 验收中的下读、上读、warm sweep
和会话切换，不是纯滚动区间；inclusive 样本重叠。** 这些只用于选择实验方向，不用于
宣称可实现的加速比例，也没有将框架剩余布局全部归给用户气泡。

## 固定二进制对照

每个实验各冻结一个 Release 二进制，在内部切换原策略与候选。每种场景三轮交替
顺序，第二轮先候选；没有并行编译、CPU 采样或 UI 自动化。所有 18 项验收通过。
表中为三轮统计的中位数，单位 ms，不跨实验比较绝对值。

| 实验 / 场景 | 原策略 median / p95 | 候选 median / p95 | 决定 |
| --- | ---: | ---: | --- |
| 气泡 Layout 测量复用 / 下读 | 9.436 / 18.250 | 9.556 / 18.154 | 没有稳定收益，撤回 |
| 保留两侧已创建近邻挂载 / 下读 | 9.263 / 17.540 | 9.680 / 19.064 | 尾部耗时回退，撤回 |
| 保留近邻挂载 / 反复换向 | 0.441 / 1.142 | 0.425 / 1.149 | p95 无改善，撤回 |

近邻候选不创建额外行，也不扩大控制器保留窗口。换向时重新挂载次数从 113 次降到
75 次，但这一局部计数没有转化为稳定的体验指标改善，完整下读反而更慢。
换向样本为每步 16pt、0–960pt 往返十次、共 1,200 步；只覆盖开头附近，不能替代
完整下读。两个实验都保留了完整上读检查；来源与结果见 `results.json`。

`bubble-cache.patch` 与 `neighbor-mount.patch` 仅为复现实验，分别应用于基线
`3e7aa29` 的独立 checkout，不进入生产。
生产文件已恢复为主线内容。仅增加可复现换向的夹具选项，以及同 ID 用户文本增长、
变短和宽度变化的原生行回归，用于防止将来缓存或挂载策略误用旧尺寸。

## 下一步

1. 用已合并优化的新构建做真实正文滚动验收，先消除版本不一致；本轮未自动重启客户端。
2. 若新版仍明显卡顿，下一项有价值的实验是减少复杂消息的 SwiftUI 子视图/原生文本
   容器数量，例如连续段落的原生排版。应先对照排版、链接、跨段选择、搜索和流式更新，
   不能直接全面替换 Markdown 渲染器。
3. 不继续增加行缓存、预加载或业务状态包装。没有稳定收益的候选不进入生产。

```sh
bash scripts/build-navigation-preview.sh
python3 scripts/run-navigation-check.py reading --output .local/body-reading
python3 scripts/run-navigation-check.py scroll --scroll-step-points 16 \
  --scroll-reversal --output .local/body-reversal
python3 scripts/run-navigation-check.py interactions --output .local/body-interactions
```

每次使用新的输出目录。正文滚动这项体验暂不宣布收尾；当前结论是两个具体方向已被
排除，并锁定了新版真实验收与正文排版粒度的后续路径。

## 最终回归

撤回候选后，完整阅读、反复换向、搜索/选区/缩放/会话返回、同 ID 文本更新均通过。
新增用户消息尺寸回归在同一原生行内依次得到 53pt → 804pt（长文本窄列）→ 485pt
（宽列）→ 53pt（短文本），全文仍在原生文本视图中，宿主没有替换。22 项性能工具
测试通过。命令结果见 `validation.json`；生产 Sources 与本轮基线完全相同。
