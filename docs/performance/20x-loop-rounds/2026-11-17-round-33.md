## 改动（v1=afd99aa）

- **产品**（ConversationSearch.hits() 末尾，单一守卫）：`let suffixHits =
  search(...)`; `if !suffixHits.isEmpty { hits += suffixHits }`。值语义由 COW

  前缀独中查询（"第 0 轮"）的结果 hits 必须与共享节点 hits **同基地址**
  （守卫被消费；remove-guard 变异体死）；后缀有命中查询（café）必须**不同
  基地址**（拼接仍在；always-skip-concat 变异体死+四制度字节全等连带死）。
