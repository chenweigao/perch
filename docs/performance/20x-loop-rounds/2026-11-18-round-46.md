## 结论

round-45 留档的开放候选 `Snapshot.presented`（5.24% inclusive，其中
`Presentation.parents` 427 样本 / 3.65%）在本轮完成了**成本定位**：

- `Presentation.parents(of:into:)` 每次更新都把最新行的 fold 记录写入
  `earlier.foldParents`。探针显示 **1,706 次调用、平均入参 map 394 项、每次约 36 条
  fold 写入，且 `changes == foldedRows`（61,829 / 61,829）——没有任何一次是空写**。
- 入参 map 与缓存中的 earlier Presentation 共享，第一次写入必然触发整字典
  **COW 复制（O(map)）/每次更新**。这是 3.65% 的主要构成（叶帧 65% 为
  retain/bridgeRetain，6% 为 `_NativeDictionary.copy()`）。
- 消除该复制需要把 `foldParents` 改成共享/持久化结构，或拆成 earlier+tail 两段；
  但 `foldParents` 是 `[String: String]` 且被 `Sources/AgentWorkbench/
  ConversationTranscriptView.swift:368` 直接消费——**本循环红线不碰 AgentWorkbench**，
  类型无法变更。源码里 COW 复制也是既有明文取舍（`ConversationPresentation.swift:138、
  317`）。

因此该候选在红线内**无最小可采纳改动**（既无空写快路径，也不能换表示），本轮不立项。
