# Perch v0.6.0

状态与总结回归正文、右栏任务面板减法、提醒路由与品牌视觉更新。

## 正文原位状态与 Recap

- **移除底部独立状态栏**：去掉正文与输入框之间的 `ConversationActivityBar`，输入框上方不再常驻状态条。
- **阶段总结与进度原位呈现**：进行中的阶段标题（含外部摘要模型精炼结果）直接显示在正文 `KimiActivityView` 折叠头上，并在有真实进展时扫光（`ShimmerGlint`）；右侧以纯文字提供计划步数 `c / n ›` 与本轮文件增删 `+a −d` 快捷入口。
- **Recap 常驻回复底部**：已完成轮次的 `Recap` 按钮常驻最新回复底部操作栏（复制按钮旁），切换会话不丢失。
- **待确认胶囊与流式性能**：滚离底部时，待确认或待回答事项自动升级为右下角橙色「返回最新」胶囊；去掉思考与工具行的秒表计时，并消除长文流式输出时的异步级联重刷。

## 右栏任务面板与产物路径

- **纯静态清单定位**：右栏任务面板去掉与正文重复的阶段叙事、用时拆解与运行中沙漏空态；舒展「编辑文件」行高并隐藏 `+0 −0` 无效统计。
- **产物路径解析修复**：修复从右栏「文档与产物」打开相对路径、worktree 路径、`Read` 工具读取路径与 `~/...` 路径时误报“文件不存在”的问题，合并正文同名简写避免重复条目。

## 提醒路由、品牌视觉与工作区

- **提醒路由与 Dock 角标**：按当前查看位置路由「该你了」提醒（应用内提示音、横幅、系统通知与 Dock 待处理角标），侧栏、通知、Goal 头部统一 `SessionTurn` 状态源。
- **深珊瑚小鸟品牌与侧栏图标坞**：采用深珊瑚底白色线条小鸟图标与侧栏线条 Agent 标识；侧栏底部收拢为紧凑图标坞，把纵向空间留给会话列表。
- **命令行浮窗与协议更新**：会话正文底部新增纯 SSH 命令行浮窗（Command Line Island）；接入 Codex 异步提问卡片（桥接协议 v12）；优化数学公式渲染与缓存性能。

## 升级

- 源码用户：`git pull && scripts/build.sh`。
- 二进制：Releases 下载 `Perch-0.6.0-*.zip`，首次打开右键 → Open（ad-hoc 签名，未公证）。
