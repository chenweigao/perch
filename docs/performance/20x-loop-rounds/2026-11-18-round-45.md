# Round 45 — ToolVisibilityProjection 冷构建 vs 温复用（评估轮，不立项）

日期：2026-11-18。base：`84e1d2e9`（round-44 合并点）。零产品改动。

## 结论

round-44 给出的两个候选（`projectTurns` 6.36% inclusive、`Snapshot.presented` 5.24%）
本轮**未采纳任何改动**：现有证据不足以证明其中存在超噪声的可采纳收益。这是
**证据不足**的结论，不是“已证明两者都在噪声带以下”。

- `projectTurns` 的 6.36% 中，探针把进入分成 8 次冷缓存与 8 次完整缓存：
  **冷缓存 1,850 次重建 / 0 复用**（首次投影），**完整缓存 1,846 次复用 / 14 次重建**
  （页前置边界）。温路径不再整窗重算，但**并非零重建**，且探针只计次数、不计耗时，
  因此“冷构建占一半”“无法用六对 A/B 分离”都不成立。
- `Snapshot.presented` 5.24% 的完整 inclusive 中，`Presentation.parents` 为
  **427 样本 / 3.65%**（round-44 报的 2.37% 只是四桶消费方份额，不是完整成本）。
  其叶帧含 `_NativeDictionary.copy()`——增量插入不排除窗口级拷贝成本，**该候选保持开放**。
- 温路径残余没有可用的耗时测量，无法给出可采纳收益的证据。

因此 round 45 **不立项**，停止规则计数 2/3 → **3/3**，停止规则①（连续三轮无
超噪声可采纳收益：round 43、44、45）机械触发；但“无候选”不等于“候选已证否”。

## 方法学入册

- inclusive 份额不能直接当作可攻头寸：必须先区分**冷/温路径**与**每次进入的复用率**。
- 计数探针只能回答“是否重算”，不能回答“重算占多少时间”；收益判断仍需耗时测量。
- 消费方归因份额（如 `parents` 2.37%）不等于该函数的 inclusive 成本（3.65%），
  引用时必须写明口径。
