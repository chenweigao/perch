# Perch v0.8.1

侧栏悬停体验打磨，CI 构建提速。

## 侧栏

- 悬停预览改为单一面板在行之间移动，减少跳动；省略号按钮改为扁平样式。
- 行操作改为原生菜单并增加按压反馈，悬停预览更安静。

## 内部改进

- CI 并行化 fixture 编译、复用预编译依赖并缓存 SwiftPM，构建更快更稳定。

## 下载与升级

- 从本页下载 `Perch-0.8.1-*.zip`，解压后替换应用。
- 需要 macOS 26 或更新版本。应用为 ad-hoc 签名，未经过 Apple 公证；首次打开按系统提示操作。
- 源码用户可拉取 `v0.8.1` 后运行 `scripts/build.sh`。
