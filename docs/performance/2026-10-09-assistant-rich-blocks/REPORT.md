# 助手行富块原生渲染（2026-10-09）

## 本轮交付

在纯散文助手行（前一轮）基础上，原生行准入扩展到标题、代码卡、分隔线、仅含
段落的引用、以及段落/嵌套列表（深度四层以内）。表格、附件和更深的嵌套保留
SwiftUI 渲染器。解析一次完成并预先构建属性字符串；块视图按位置复用同类型，
回收时拆解全部块容器并把清空的文本视图归还共享池，回收壳不保留会话内容。

代码卡为纯 AppKit：overlay 横向 `NSScrollView`、不折行文本容器、语言标签和托管
复制按钮；列表 marker 按 SwiftUI 对齐参考线使用的同一首行基线常数对齐。

## 功能验证

- `assistant-rows`：36 组对照（9 种内容 × 700/340pt × 深浅色），行高与所选
  glyph 位置差均 ≤1pt；覆盖标题、代码、引用、嵌套列表、横向溢出长代码行。
- 契约：富块进出原生路径保持外层行身份；表格/附件/列表内代码回退 SwiftUI；
  代码卡复制按钮复制代码源本身并渲染反馈；长行横向溢出；回收池上限 16 且
  清空内容。流式、压缩摘要、运行上下文、RTL 仍不进入原生路径。
- `user-rows`、`interactions`、`reading`、`paragraphs`、`disclosure`、
  WorkbenchChecks 通过；live SSH 检查未配置，跳过。

## 固定二进制 A/B（`NAVIGATION_NATIVE_ASSISTANT_BLOCKS=0/1` 叠加在散文原生行之上）

200 轮混合正文，顺序 a1–b1–b2–a2–a3–b3，测量期间无并行编译。数值为每轮主线程
单步布局/绘制处理时间的中位数/p95（ms），完整数据见 `results.json`。

| 场景 | A（散文原生）median/p95 | B（散文+富块原生）median/p95 |
| --- | --- | --- |
| 首次整段扫读 | 10.59–10.87 / 15.97–16.93 | 10.92–11.22 / 17.31–17.96 |
| 已读历史返回 | 9.60–11.09 / 17.34–20.99 | 9.91–10.37 / 17.10–17.46 |
| 同屏小范围往返 | 4.21–4.46 / 9.16–9.67 | 3.82–4.55 / 8.64–10.36 |
| 完整下读（reading p95） | 12.44–12.86 | 12.78–13.34 |

原生覆盖面从 79/279 条助手行升至 157/279（约 56%）；`markdown_parse`
156 → 78 次，`host_measure` 316 → 244ms（-23%）。端到端步进时间为中性：首次
扫读 B 略慢（每轮均高出约 0.3–0.5ms 中位数），历史返回 B 略快，差异与轮间
噪声同量级。不声称整体滚动性能改善；本轮的价值是把大部分已完成正文移出
SwiftUI 图，并为后续表格原生化提供同一条路径。

## 复现

```sh
bash scripts/build-navigation-preview.sh
python3 scripts/run-navigation-check.py assistant-rows --output .local/assistant-rows
```

A/B 原始运行位于本机 `.local/blocks-ab/`（测量于 `adc45c7`）。随后 rebase 到
main `2b53207`（并入 #86/#88/#89，仅触碰用户行气泡背景与 Claude/Codex 连接，
不进入助手行路径），`assistant-rows`/`user-rows`/`interactions` 重跑通过；
A/B 因机器上持续存在并行编译未能在无干扰条件下重跑，两臂共享同一基线的
对比结论不受影响。

## 边界

- 表格与附件行的 SwiftUI 开销不变；这是剩余的单一最大渲染成本。
- 夹具不能证明真实触控板体验；VoiceOver 未验证（同前轮）。
- 代码卡复制状态在源编辑后保留，与 SwiftUI 卡一致；与散文行的“换源重置”
  策略不同，沿用各自原渲染器的行为。
