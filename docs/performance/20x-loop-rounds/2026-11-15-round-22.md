## 改动（v1=e2ff3c0 → v2=e14c25d；单文件 `ActivityNarrative.swift` + 新钉死文件）

`NarrativePhaseScan`：单遍 UTF-8 字节扫描——首字节大小写折叠分桶
（256 桶静态表）、ASCII 关键词大小写不敏感字节比较、CJK 关键词字节
精确比较；命中后**双侧边界证明**（round-17 技术：前驱字节 ASCII 或串
首、后随字节 ASCII 或串尾——一切 Prepend/Extend/SpacingMark/ZWJ 标量
均非 ASCII）为**确认匹配**；边界不可判定 ⇒ 回落原规范谓词
（`lowercased().contains(kw)`，v2 起全部类别共享**单次**惰性小写化——
复核 F2）；优先级解析严格按原 if 链逐级 confirmed→fallback。

**v2 新增（复核 F1 BLOCKING 修复）**：扫描中检测 **CJK 兼容表意文字
三区**的 UTF-8 前导模式（U+2F00–2FFF→E2 BC..BF 保守、U+F900–FAFF→
EF A4..AB、U+2F800–2FFFF→F0 AF 保守），命中即**整文交回逐字保留的
legacyPhase 原链**（独立于字面匹配旗标）。评审反例（已逐字入钉）：
`"冲\u{FA55}"` 旧链经规范折叠命中"冲突"→.integrating，v1 字节扫描
无字面字节且未触发回落→.mixed——**真实行为回归**。探针实证（双平台，
归档 checks/compat-decomposition-probe-record.md）：
`decomposedStringWithCanonicalMapping` 对兼容字**不暴露**单例映射
（返回 SELF），而 `contains` **双平台都折叠**——折叠发生在规范搜索
内部；故完整性钉死改用**操作性规范等价扫描**（String 的规范 `==`/
Set 成员判定）：全 1,112,064 标量中恰 **3 个**桥接（U+FA55→突、
U+FA8E→搜、U+F96A→索——与评审反例一一对应），全部落在检测区间。
常见 CJK（E6/E8 前导）、全角标点（EF BC）、emoji（F0 9F）不触发
检测——快路径保留（v2 粗筛/正式幅度与 v1 一致即实证）。

**等价论证（v2 终版，产品注释全文在案）**：① 无假阳性——确认匹配的
关键词字符为独立 grapheme 且字节连续 ⇒ 旧谓词必命中；② 无假阴性
（ASCII）——穷举扫描钉死唯一非 ASCII→纯 ASCII 小写桥 U+212A('k') 且
32 关键词无 'k'；③ 无假阴性（CJK 规范折叠）——操作性等价扫描钉死
全部桥接标量位于三个检测区间，区间内文本整文走 legacy 链逐位复现旧
行为；④ 边界不可判定命中走原谓词 ⇒ GB9b 平台分歧（round-17 探针）
逐位保留。

## 行为等价钉死（checkNarrativePhaseSinglePass）

1. **穷举小写桥扫描**：1,112,064 标量断言纯 ASCII 小写像 ⟺ ASCII 或
   U+212A；U+212A→"k"；32 关键词运行时验证无 'k'/'K'。
2. **穷举规范等价扫描（v2，F1）**：凡与 CJK 关键词字符规范相等的非
   ASCII 标量必在检测区间（实测恰 3 个桥接，>0 守卫防扫描空转）；多
   标量序列不能经纪范组合产生表意文字（无 primary composite），标量
   扫描完备，组合面由差分模糊经验覆盖。
3. **差分模糊（round-16 v2 运行时差分模式）**：参考实现=被替换谓词链
   逐字拷贝；2,000 条 seeded 文本（碎片含 32 关键词全形态、四类 GB9b
   Prepend 邻接、Extend/ZWJ、词内组合符、İ/U+212A 桥、emoji 邻接、
   **兼容区碎片（v2 新增：冲U+FA55/U+FA8E索/搜U+F96A/U+FA55/U+2F00/
   U+2F800）**；**唯一前缀 z{index}z 保证表冷**——静态表跨
   NarrativeTextCache 实例存续，复核 F1 附注）经 projection 公共路径
   与参考实现**逐一相等**（同平台对照——旧谓词自身平台分歧，差分而非
   固定期望才是契约）；密度守卫（对抗文本 >200——v2 实测 1,130；五类别
   各 >20）。
4. **结构例**：32 关键词逐一映射 + 跨类优先级 3 例 + 无关键词对照 +
   **评审反例 4 条逐字（QZ0/QZ1/QZ2/QZ4）+ 6 个补充兼容形态**。
5. **既有 narrative 黄金 4e46d66eff016205 原样通过**（1,500 脏语料文本
   端到端：标记/空白/NBSP/emoji/é/长文本——其关键词碎片"验证测试"
   "构建""edit fix""git commit""读取 search""分析查看"直接覆盖 phase
   路径；注：该语料不含 Prepend/组合符/ZWJ 碎片——那些角落由本差分
   模糊覆盖，复核 F3 澄清两者的覆盖边界）。
