# Perch v0.5.0

夜间模式独立设计，以及一轮文件与面板体验修复。

## 夜间模式

- 夜色色板：蓝石墨画布 #1F2229，正文、次要文字、链接与 diff 语义色按测量对比度调校（正文 11.4:1，次要文字 4.7:1，均过 WCAG AA）。
- 独立的明暗 token：填充、描边、投影按外观分别定义；夜间靠更亮的表面与描边分层。
- 终端暗色盘与画布统一，不再有中性灰"补丁"。

## 窗口玻璃四档调节

设置 › 界面 › 窗口玻璃：通透 / 轻透 / 标准 / 克制，日夜共用。玻璃下垫层强度可调，浅色为白色、深色为蓝石墨，高饱和壁纸下侧边栏不再抢戏，也保留桌面气息。

## 体验修复

- 文档与产物：已删除的文件保留条目但置灰并标注「已删除」，不再点进死胡同；文件重新生成后自动恢复。
- 相对路径产物（如 `_evidence/<task>/shot.png`）增加有界的后缀搜索兜底，点开不再误报不存在。
- 浅色会话选中卡改为淡灰蓝，定位更直接；正文卡片阴影收窄、更轻。

## 升级

- 源码用户：`git pull && scripts/build.sh`。
- 二进制：Releases 下载 `Perch-0.5.0-*.zip`，首次打开右键 → Open（ad-hoc 签名，未公证）。
