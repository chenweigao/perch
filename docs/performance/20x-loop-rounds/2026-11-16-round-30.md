## 行为等价钉死（checkConversationEntryCache，新）

- **Part 1 机制**：键字节精确（NFC/NFD query 异键；entryID/query 边界不可歧义拼接；
  options/running 位区分）；**验证谓词是唯一复用门**——同 ID 编辑消息拒绝复用（值层
  失败）、**规范相等 NFD 重建拒绝复用**（值层通过、渲染字节层拒绝=round-12
  sameRenderedMessages 推理的跨实例化）；精确载荷成本记账（estimatedCost 公式逐值）；
  budget-0 永不入表（无缓存 oracle 制度）；具体 LRU（touch 保留+受害者身份+新插保留）；
  非空表超大拒绝（哨兵零扰动）；locale 世代（真实通知 POST→整表丢弃）；removeAll
  （诊断语义）；8×100 并发风暴+单份记账（==25×cost）。
- **Part 2 端到端**（round-27 语料：NFC/NFD 变体、独立消息重复 source、display math、
  URL/代码）：四制度（budget-0 双层 oracle / shared 冷 / fresh / shared 温）× 6 查询
  规范级+**逐 hit UTF-8 字节级**全等（round-27 v5 byteShape 比较器）；**跨实例
  staleness**：温缓存后以同 ID 编辑窗口经新实例搜索，与 budget-0 oracle 规范+字节
  全等（skip-verification 变异体死于此）且编辑后新命中（BETA）在场；running 标志
  隔离（true/false 不串节点）。

## A/B（同机交替六对；采纳只看 Mac；采纳数据 v1=8732e11）

**方法论**：基线=原始 4f90b88 树（tests 引用新公开类型 ConversationEntryCache 无法在
基线编译——round-27 同款披露的不对称）；采纳骑 cold+reopen 两个 ms~百 ms 量级**配对**
指标（reopen 基线自 round-27 起即输出），µs~ms 护栏按 spread 分类器；量级论证为风险
限定（round-28 F8 口径）。摘要器=round-27 副本（本轮无单侧指标）。

### Mac mini（仲裁侧；采纳数据）

- **find_bar_reopen_query：139.525 → 15.88ms = -88.62%**（精确 -88.6185%，最差对
  -88.04%，spread 9.84%，六对全分离）⇒ **分类器通过，本轮主采纳指标**。
  样本 cand [15.82, 15.40, 16.74, 16.19, 15.94, 15.24]。
- **find_bar_cold_query：621.64 → 642.51ms = +3.36%**（worst +4.50%，spread 1.25%，
  六对同向正向分离）——**store 路径成本，真实产品效应**（Linux 同向 +2.90% 佐证，
  非布局伪影）。处置=**明示接受权衡后采纳**（round-26 F2 先例）：首开一次性 +20.9ms，
  此后每次重开/显式重搜 -123.6ms——**第一次重开即回本**；产品形态中重开/重搜是重复
  事件、首开是单次事件；bench cold 每迭代注入新缓存=每次都付 store 零受益，是该
  权衡的最坏形态而非典型形态。
- **90 项配对指标 positives_beyond_spread = 仅 cold 一项**（即上述权衡项）；其余护栏
  全带内：query_update +1.79%（spread 11.54%）、older_page 0.00%（3.47%）、
  chain_total 0.00%（6.90%）。
- 单对例外 11 处：cold 自身 6 对（越带回归的逐对形态）+ cold@500 P1（5.75 vs 5.14）

### 采纳判定

Mac 仲裁：主指标 find_bar_reopen_query **-88.62%**（六对全分离）分类器通过；
find_bar_cold_query **+3.36% 越带回归按 round-26 F2 先例明示接受权衡后采纳**
（首开一次性成本 vs 每次重开 -123.6ms，第一次重开即回本；两平台 cold 回归方向与
幅度一致=真实效应，如实计入权衡而非伪影消除）；其余 89 项护栏零越带回归。
⇒ **采纳**。**停止规则计数维持 0**（本轮采纳）。
