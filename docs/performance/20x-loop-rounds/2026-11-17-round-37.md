### 双重验证发现（本轮主要新知识，入队列）

cost-reuse 循环（ConversationPresentation.swift:601 逐消息深 ==，~2.8%）
与 TV sameWindow 验证（~5%）对**同一后缀字节各验证一遍**（前者服务
retained-cost 复用，后者服务 chunk 复用）。统一可省 ~3%，但三重红线：
(a) cost == 是缓存准入语义门（弱化=准入行为变化，budget-0 钉死族）；
(b) sameWindow 是 chunk 复用正确性门；(c) 统一需 TV↔model 新 API
（架构耦合，非最小修改）。物理同一性快路径（string/array buffer 地址
比较+精确回退，语义零变化）估算收益 ≈2.8-3.5%——**低于分类器可信阈**
（spread 4-10%），单独立项预期不可裁决 ⇒ 不消耗正式轮，留队列待
红线评估或更大机制合并时一并处理。

### 裁决

双重验证 + O(页) 投影 + O(output) 装配——rounds 35/36 已移除其中的
可移除字典/哈希机械（累计 Mac -49.8%）。按循环规则以「记录在案的不
采纳结论（报告+INDEX 行）」结束本轮；**停止规则计数 1/3**。
