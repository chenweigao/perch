## 改动（v1=afd99aa）

- **产品**（ConversationSearch.hits() 末尾，单一守卫）：`let suffixHits =
  search(...)`; `if !suffixHits.isEmpty { hits += suffixHits }`。值语义由 COW
  保全：空后缀时结果与节点/earlier 共享存储，调用方变更时才复制、永不写穿
  缓存；非空后缀照旧拼接为结果自有存储。产品常见受益形态=查询只命中历史而
  live turn 无匹配（流式重搜每次更新、find bar 重开）。
- **钉死**（消费级，round-32 否定清单教训直接应用）：缓冲区同一性双向断言——
  前缀独中查询（"第 0 轮"）的结果 hits 必须与共享节点 hits **同基地址**
  （守卫被消费；remove-guard 变异体死）；后缀有命中查询（café）必须**不同
  基地址**（拼接仍在；always-skip-concat 变异体死+四制度字节全等连带死）。
- **bench**：reopen 指标改 4 位小数打印（0.10ms 打印地板处量化即 10% spread
  不可裁决——round-32 后记预告的计时面扩展）；基线侧仍 2 位（不对称披露）；
  reopen 注释块更新（空后缀共享存储形态；bitwise 机制表述 v3 修正为双平台
  实测通过——v1 初稿的 padding 论撤回）。
- **迭代**：v1=afd99aa（守卫+钉死+打印面）→ v2=cb4d4a1（评审驱动钉死升级：
  三路同一性+投毒隔离，test-only）→ v3（bench 注释机制表述修正，test-only；
